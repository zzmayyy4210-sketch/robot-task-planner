# 三分钟演示

在项目根目录安装依赖后运行 `python demo.py`，即可依次看到三种行为，无需手动输入中文。

| 输入 | 结果 | 是否生成步骤 |
| --- | --- | --- |
| 把桌面上的红色方块放进左边的盒子。 | ready，red_block → left_box | 是，5 步 |
| 把蓝色方块放进盒子 | clarification，询问左右盒子 | 否 |
| 倒水 | rejected，unsupported_input | 否 |

## 结构化任务怎么产生

自然语言 → 输入检查 → 规则解析 → Pydantic 字段校验 → 缺失信息检查 → 追问或步骤模板。

`ready` 表示任务字段完整，不代表真实机器人已经执行。当前没有视觉感知、路径规划算法或硬件连接。

## 如何展示自己的理解

先演示成功任务，再演示缺少目标的任务，最后演示不支持的动作。解释为什么不能猜测目标，以及为什么生成计划与执行计划是两个环节。

## 中文显示问题

项目源文件采用 UTF-8。Windows 终端可使用 `python -X utf8 demo.py`。编辑器保存文件时也应选择 UTF-8。GitHub 网页本身支持中文，无需开启网页翻译。
